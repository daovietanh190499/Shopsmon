Anthropic launches Claude Ship (beta): agents that review, fix and approve pull requests under each team’s policy, made up of Code Review, PR Steward and Claude Approvals

2026-11-23 · Source: Anthropic

According to Anthropic (Nov 23, 2026), Claude Ship is a set of agents that work on GitHub pull requests (PRs), launched in beta. It combines Code Review (already generally available) with two new beta agents, PR Steward and Claude Approvals; together the three take a PR through review, fixes and an approval decision. Code Review examines a PR against the codebase through multiple lenses, collects findings, verifies them adversarially, categorises them and posts them to the PR, with Quick, Standard and Deep review levels for each repository. Anthropic says that on the Claude Code team, where Claude’s review is one layer of a broader process, merged PRs more than doubled from June to September while the share reverted fell by more than 40%. PR Steward steps in on failing CI checks, merge conflicts and review feedback from Code Review, other review tools or people; after every push it comments with what it changed and how to undo it. Developers can steer it by commenting @claude with an instruction or stop it with @claude stop; PR Steward is designed not to approve or merge pull requests. Claude Approvals applies an approval policy that the team writes as a file in the repository: Claude can approve routine changes on its own if the policy allows it, or require deeper human sign-off for certain scenarios. Anthropic describes it as working like a smarter CODEOWNERS file; it can weigh several signals, such as Code Review findings or classifiers the team defines in natural language, and Anthropic recommends enabling it in observe-only mode first, before configuring branch protection to require Claude Approvals’ green light. There are two ways to start: developers use the new /ship command in Claude Code (Claude pushes the change, opens the PR, reviews it and works on feedback and failing checks; what can merge depends on the developer’s permissions and the repository’s branch rules), rolling out in Claude Code and the desktop app from Nov 23; administrators turn on Code Review and PR Steward per repository, while Claude Approvals starts when a connected repository has a policy file on its default branch, and they choose the review level, when reviews run and a monthly spend limit. Claude Ship works with existing branch protection and required checks. On availability, Claude Ship is offered on Claude Team and Enterprise plans for repositories on GitHub, and is not available to organisations with Zero Data Retention, the HIPAA configuration or customer-managed encryption keys. Usage is billed on tokens: Claude Approvals has no base charge, but classifiers in a policy are billed on the tokens they use, and a policy that uses Claude’s review triggers a billed Code Review even in observe mode; running /ship counts as regular Claude Code usage. Eligible Claude Enterprise organisations can claim at least $10,000 in Claude Ship credits to use within 30 days of claiming, with a claim deadline of Jan 15, 2027. Anthropic’s documentation notes that Claude Ship uses AI and may miss bugs, security vulnerabilities or other issues, and warns that if GitHub auto-merge or a merge queue is used with a policy that does not require a person’s approval, a change can merge without anyone acting.
