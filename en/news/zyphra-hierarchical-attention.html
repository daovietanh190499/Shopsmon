Zyphra ZHA: hierarchical sparse attention with subquadratic complexity for long context

2026-11-02 · Source: Zyphra

Zyphra introduced Hierarchical Attention (ZHA), which builds a hierarchical tree and searches it to select the relevant tokens for each query, reaching subquadratic complexity. Existing pretrained models are adapted with a distillation phase of only a few billion tokens. Per Zyphra, on RULER-13 at 256K tokens the wide-tree model scores 96.2% (96.0% for the original dense model); on LongBench v2 the deep-tree model scores 63.4% vs 58.0% for dense attention while attending to ~1.1% of the KV cache during decoding.
