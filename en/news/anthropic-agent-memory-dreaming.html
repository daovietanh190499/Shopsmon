Anthropic details how Claude uses agent memory: notes, wikis and offline “dreaming” that lifts wiki-only scores from 13% to 48%

2026-11-06 · Source: Anthropic

According to Anthropic's engineering post (by Lance Martin, published Nov 6, 2026), agent memory is knowledge Claude gains from experience and keeps between sessions as context it can read later; it excludes changes to weights, in-context learning and compaction. The post describes four components: memory notes, representations such as wikis, context preloaded at the start of every session, and “dreaming” — an offline process that re-reads session logs and notes to correct mistakes, merge duplicates, build links and promote important notes to the preloaded layer. On CL-Bench 1.0 (database look-up question answering; each question starts a fresh session with only a memory folder persisting), Anthropic says Claude Opus 5, Opus 5.5 and Sonnet 5.5 “closed the loop” of learning: writing validated rules together with how they knew the rule was true. In Pokémon Red, about 10,000 steps in, Sonnet 3.7 had written 413 memory files across 225 folders and earned one badge, while Fable 5 wrote nine files in two folders plus a single global.md and earned four badges; Opus 5.5 kept a small notes folder, rewrote it as it played and beat the game. When told to “record only failures”, Opus 5 and Opus 4.7 lost much of the boost memory gave them; according to Anthropic, for stronger models freedom to judge salience worked better than fixed rules, while guidance helped older models most (Sonnet 4.6 nearly doubled its score when prompted to read memory and test its theories). On dreaming: over Stainless's internal corpus (about 350,000 files, roughly 420M tokens) with 25 questions, scaling dreaming from 2 to 128 sessions raised the wiki-only score from 13% to 48%; combining search and wiki raised the score from 54% to 61% (search alone: 53%) and saved about 20,000 tokens per question. On 24 questions about a merger, Claude scored 87% using the wiki against 73% with search alone; on another LAB task the wiki showed no clear gain, and on a further one the wiki grew larger than the source documents. In a contracts test, several agents writing one shared table kept 41 of 57 facts (72%); with one page per contract written by a single agent, all 57 survived. Anthropic notes the preloaded layer has to stay small (Claude Code loads only the first 200 lines or 25 KB of MEMORY.md) and that dreaming requires compute.
